### Cross Platform Driver Payments Application for GlossRide

Built and deployed an iOS and Android payments application used by **33 private hire drivers**.

**Tech Stack:** React Native, Node.js, Express.js, Stripe, REST APIs

**What it does:**

• Driver onboarding  
• Job allocation and scheduling  
• Invoicing and fee calculation  
• Stripe payment workflows  
• Customer receipts and transaction tracking  
• Backend API automation

### Cloud Based Analytics Platform for KeyReply

Built a cloud analytics platform that processed **5,000 plus healthcare chatbot interactions** to surface engagement, sentiment, and service quality insights.

**Tech Stack:** AWS, PySpark, FastAPI, HDFS, REST APIs

**What it does:**

• Processes chatbot interaction data  
• Tracks user engagement and service quality  
• Supports healthcare chatbot adoption  
• Provides analytics for operational decision making

### Insurance Claims Automation Platform

Built an AI powered insurance claims platform for dashcam based claim review.

**Award:** 2nd Place, Agent Forge AI Hackathon  
**Tech Stack:** FastAPI, React, VideoDB, Kimi AI

**What it does:**

• Reviews dashcam based claim evidence  
• Performs policy reasoning  
• Supports fraud detection  
• Generates trust scores  
• Recommends claim outcomes
